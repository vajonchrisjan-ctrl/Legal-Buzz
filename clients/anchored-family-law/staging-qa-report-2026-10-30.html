Fix

The staging address is saved inside the SEO settings

Canonical tags and social URLs on all 38 indexable pages point at the staging host. The sitemap lists 69 staging URLs, four Rank Math redirect rules send visitors to staging addresses, and the attachment redirect default points there too. If any of this carries over unchanged, Google is told that the staging address is the real site.

Next: run a domain search-and-replace at go-live (or confirm Kinsta's push-to-live does it), then re-check canonicals and the sitemap on the real domain.

Inherited from live

Each of these is identical on the live site, so they are not new faults. They are the on-page fixes already planned for the rebuild.

SEO

No structured data anywhere

Rank Math's Schema module is switched off, so none of the 44 pages outputs JSON-LD. The organisation and article markup Rank Math is set up for is never produced.

Design

The Poppins heading font never loads

Elementor's saved font stylesheet has 54 font addresses written as http://anchoredfamilylaw.com.au/…. Browsers block them as insecure content, so headings fall back to a system sans-serif. Live is affected in the same way.

SEO

Stored redirects are switched off, and two are wrong

The Redirections module and the 404 monitor are both off. Four old rules from February 2026 are stored anyway. /blog points to /knowledgebase and /knowledgebase points back to /blog, which would loop if anyone turned the module on. Another maps services/charter-boat, which belongs to a different site.
