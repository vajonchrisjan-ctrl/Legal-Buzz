# Creative Studio
Prompt an idea → Research, Writing and Design agents produce Ads, Proposal and Post creative, previewed in a dashboard.

    cd creative-studio
    ANTHROPIC_API_KEY=sk-... node server.js   # live agents (optional CLAUDE_MODEL override)
    node server.js                            # demo mode, no key needed
    open http://localhost:3000

No dependencies (Node 18+).
